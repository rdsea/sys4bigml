The five patterns

Each pattern is an on/off switch. On runs the pattern; off runs the simple version most people write first. Try it: turn all patterns off, run a task, then turn them on one at a time and compare the results.

Each card says why the pattern is needed, what on and off do, and what goes wrong without it. Switches that the selected task doesn't use are greyed out.

Run a task

This is separate from the five patterns. With “code counts”, the numbers are always exact, because the LLM is never asked for them. With “the LLM counts” and structured outputs on, the mission may stop as aborted if the model keeps getting a number wrong: the check refuses to send a wrong map.

The mission starts by sorting four built-in field reports (medical, structural, logistics, and one junk report). That is where routing runs.

Try a junk report such as “Radio check, testing one two three”. With routing on, it is dropped after one short classify call; with routing off, it still gets a full answer.

Correct answer: A2 has two people (confidence 0.91 and 0.84). With the dispatcher on, the agent reads the drone data and llama3.2 answers “2”. With it off, the model guesses (0, 5, 12, or “not enough information”).

Then try a two-part question, e.g. add “…and what is the weather there?”. Small models often answer after the first tool call without fetching the second fact, and sometimes run out of steps.

Observability

Expand “Where to see it” on any pattern above to find what it changes in the traces and metrics. The analytics tool reads the same traces from Jaeger:

python3 tools/mission_analytics.py --feature=pattern_effect
python3 tools/mission_analytics.py --feature=summary_interactions
python3 tools/mission_analytics.py --feature=llm_reliability
python3 tools/mission_analytics.py --feature=human_reviews
  • Jaeger — traces (service: agent_service; filter by tag run.patterns)
  • Prometheus — metrics (agent_llm_retries_total, agent_unchecked_errors_total, …)
  • Grafana — dashboards
  • Langfuse — LLM interaction logs (optional)
